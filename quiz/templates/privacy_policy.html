Privacy Policy

How AdaptiveQuiz handles information

This simple policy describes the information used by this student project and demo website. It should be reviewed and customized before any public production launch.

Information We Collect

AdaptiveQuiz may collect information you provide when creating an account, using quizzes and learning features, or submitting the Contact form.

Account Information

An account includes a username and email address, together with the password managed by Django's authentication system. Passwords are not stored as plain text.

Quiz and Learning Activity

For signed-in users, the site stores quiz attempts, answers, scores, accuracy, topic performance, and related learning progress so the platform can provide its dashboard, history, review, and adaptive practice features.

How Information Is Used

Information is used to provide authentication, quizzes, learning notes, performance views, adaptive practice, and responses to Contact submissions. This project does not describe or promise advertising or sale of user information.

Data Storage

Application data is stored in the PostgreSQL database configured for this installation. The actual hosting, retention period, backups, and deletion process must be documented by the administrator before production use.

Cookies and Sessions

Django uses cookies and server-side sessions for authentication, security, and temporary quiz state. Browser settings may affect these features.

Third-Party Services

The project includes an optional Google Gemini API integration for question generation when an administrator configures it. Any production deployment should review that provider's terms and privacy documentation and disclose what data, if any, is sent.

Data Security

The application uses Django's built-in authentication and CSRF protections. No website can guarantee absolute security; production administrators must configure secure secrets, HTTPS, database access, backups, and deployment settings.

User Rights

Users should contact the site administrator through the Contact page with questions about access, correction, or deletion of their information. A production policy should define the applicable rights, identity checks, and response times.

Children's Privacy

This student project is not intended to knowingly collect information from children without appropriate consent. A production deployment should establish an age-appropriate process and comply with applicable law.

Changes to This Policy

This page may be updated as the project changes. The administrator should add an effective date and notification process before public production use.

Contact Information

For privacy questions, use the Contact page. An official support email, legal entity, and physical address should be added here before public production use.
